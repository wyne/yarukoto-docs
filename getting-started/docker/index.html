Running it with Docker

Requires Docker with Compose v2. Nothing is built on your machine: the compose file pulls the prebuilt ghcr.io/wyne/yarukoto image (amd64 and arm64), so all you need is the compose file itself.

The same version and short sha appear in the app under the sidebar’s server sheet, so you can tell whether an instance actually picked up an update. commit is empty for a local build unless you stamp it: GIT_SHA=$(git rev-parse HEAD) docker compose build. Published images (ghcr.io/wyne/yarukoto) always carry it, and the short sha matches their sha-<short> tag.

Updating

Section titled “Updating”

Your database lives in ./data on the host and is untouched by updates. Watchtower and similar tools work too; pin a sha-<short> tag instead of latest if you’d rather choose when to move.
